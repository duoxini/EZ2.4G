## 实现及离线结果

- 新增独立 `mchose_k99_protocol.py`：官方精确型号身份、共享接收器产品名判别、
  GLW FA FB 07 payload/native framing 解析；充电通知保留未知百分比。
- `my_devices.py`：专用 read_k99_v3、正常模式 collection 过滤、三秒共享预算、
  读取计数和错误诊断、关闭句柄、专用派发、禁止通用/用户协议回退。
- 新增 `--once --k99-only`；与 rapoo-only 冲突或缺少 once 时拒绝运行。
  此入口不读其他外设、不读写配置/历史缓存；仍需枚举 HID 路径以定位目标。
- 不保存原始 K99 报告，正常键盘 collection 不会被读；只输出经验证的电量/计数。
  产品名缺失或与 K99 V3 不符时，专用入口不尝试打开共享 3033 接收器。
- 运行前原有 27 项全部通过；改动后共 43 项全部通过：原有 27 项回归，
  新增 5 项协议测试与 11 项集成测试。全部是合成字节、AST 提取、mock，
  不导入 `my_devices.py` 的 Windows/HID 顶层，不枚举或打开设备。
- 新测试覆盖放电 0/100 边界、范围/截断/错误类型/前缀、充电未知值、
  产品名碰撞、boot/键盘 collection 排除、句柄关闭、超时/空包/读取错误、
  专用派发、无通用回退、限定 CLI 和配置/缓存隔离。

